# Cafe There — Digital Menu + Customer Ordering

Files: `index.html`, `styles.css`, `app.js`.

Customer flow: Home → Menu → Product → Add to Order → Your Order → Place Order → Pay at Counter confirmation.

The current ordering step is customer-side only. It does not yet send the order to staff or use a database. The next phase can connect this to a private staff dashboard using a Cloudflare Worker + D1.

Deploy all three files together to the existing Cloudflare static deployment.
